# 자비스 (jarvis-data)

**먼저 말을 거는 개인 AI 에이전트.** 애플 생태계와 브라우저 기록에서 개인 데이터를
자동으로 모아, 그 사람의 평소와 어긋나는 지점을 감지하고 로컬 LLM이 판단해 말을 건다.

데이터가 사설망 밖으로 나가지 않는다. 그게 기능이 아니라 **아키텍처 제약**이었다 —
검색 기록·결제 내역·위치를 클라우드 AI에 던질 수는 없으니, 추론 서버를 집에 세웠다.

```
기존 헬스 앱은 묻지 않으면 답하지 않는다.
알림을 늘리면 스팸이 되어 꺼진다.
      ↓
말할 가치가 있을 때만 먼저 말한다.
```

이 두 힘이 당기는 지점이 이 레포의 거의 모든 설계 결정을 설명한다.

## 어떻게 생겼나

```
  아이폰 단축어          맥 수집기            export.xml
  수면 · 심박 · 위치      크롬 기록           일회성 백필
        └──────── Tailscale ────────┘
                     ↓
              자비스 서버 :8100
                     │
        ┌────────────┴────────────┐
        ↓                         ↓
   반응 루프 (30분)          회고 루프 (주 단위)
   숫자를 보고 즉시 판단      텍스트를 훑어 믿음 갱신
        ↓                         ↓
   "어젯밤 2.7시간 잤어"     "요즘 이사를 알아보네"
        └────────────┬────────────┘
                     ↓
              vLLM :8000 (로컬)
                     ↓
                  텔레그램
```

**루프가 둘인 이유**는 재료가 다르기 때문이다. `"전세자금대출 금리"` 일곱 개를 모아
평균 낼 수는 없다. 숫자는 접히고(평균·합계) 트리거가 즉시 반응하지만, 텍스트는
접히지 않고 쌓였다가 회고가 요약한다.

|---|---|

| 크롬 수집기 | ✅ 설치는 안 됨 |
| **폰 수집** | ⚠️ **2026-08-29부터 멈춤** |

| 믿음 → 발화 연결 | ❌ 알아낸 걸 쓰지 않고 있다 |

솔직하게 적는다. "다 돈다"고 믿고 시작하면 첫날에 헷갈린다.

## 실제로 나온 것

**통근 경로가 통째로 잡혔다.** 위치에 자동화 라벨을 붙인 뒤:

```
07:29  집        →  07:32 정류장  →  07:39 역  →  08:15 도착
       도보 4.3km/h    버스 11.7km/h    지하철 20.8km/h
```

이틀 연속 오차 2분 이내였고, **아침에 사라진 지점에서 저녁에 2m 오차로 다시
나타났다.** 그 좌표가 타는 역이다. 갈 때 34분 / 올 때 36분으로 대칭이라 같은 노선
왕복인 것도 확인됐다.

**회고가 브라우저 기록에서 관심사를 뽑아냈다.** 220건에서 3건, 그리고 **근거가
1개뿐인 것 1건을 기각했다.** 근거 없이는 믿음이 만들어지지 않는다.

## 시작하기

```bash
git clone git@github.com:rngusrb/jarvis-data.git && cd jarvis-data
python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
cp .env.example .env            # 토큰은 직접 만든다
.venv/bin/python scripts/harness.py all
```

`harness all` 통과가 이 레포의 **"완료" 기준**이다. `pytest` 단독은 완료가 아니다 —
정적 검사와 Doc Lint 가 빠진다.

서버·폰·수집기·텔레그램 네 조각을 세우는 절차는 [docs/SETUP.md](docs/SETUP.md) 에 있다.

```bash
.venv/bin/python scripts/harness.py src/core/       # 폴더 하나만
.venv/bin/python -m app.reflect --show              # 자비스가 지금 뭘 믿는지
.venv/bin/python -m src.sectors.commute.inspect     # 위치를 사람 눈으로
```

## 같이 개발한다면

**코드는 공유하고 데이터는 안 한다.** `data/*.db` 에는 수면·위치·브라우저 기록이
들어 있고 gitignore 되어 있다. 각자 자기 인스턴스를 돌리고, GPU만 나눠 쓴다.

자세한 구성은 [docs/SETUP.md 의 "동료로 합류하기"](docs/SETUP.md#6-동료로-합류하기) 절에.

---

## 세 가지만 기억하면 된다

1. **`harness all` 통과가 완료다.**
2. **폴더 `_GUIDE.md` 를 먼저 읽는다.** 거기 금지사항은 전부 실제로 당한 것이다.
3. **금지사항을 추가할 땐 사고 이력을 같이 적는다.** 이유 없는 규칙은 다음 사람이
   지운다.

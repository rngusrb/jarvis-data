# src/sectors/commute/ — 폴더 가이드

## 역할

이동 패턴을 소유한다. 위치 자동화가 주는 것은 **사건**(언제·어디서·왜)이다 —
`events.py` 의 위치 카드. 퇴근·출근 시각처럼 "하루에 숫자 하나"인 것만 관측치다.

**이 폴더가 소유하지 않는 것**: 접는 계산(→ `core/folding`), 판단 실행(→ `brain`),
다른 섹터. health 의 수면 데이터를 참조하지 않는다.

---

## 핵심 패턴

### 값이 곧 시각이다
```
17.5  →  오후 5시 30분
```
**이유**: 수면·심박은 측정 표본이지만 퇴근은 **사건**이다. 측정값을 집계하는 게
아니라 "언제 일어났나"가 값이다.

### 위치는 사건이다 — 접지도, 숫자로 담지도 않는다
```python
LOCATION = EventKind(kind="location", value_as="accuracy", ...)   # events.py
Event(label="wallet", lat=…, lon=…, meta={"accuracy": …})        # 사건 표
```
**이유**: 위치는 "9시에 여기, 18시에 저기"가 낱낱이 남아야 패턴이 보인다. "하루 평균
위치"는 의미가 없고, 숫자 칸(관측치)에 담으면 숫자로 취급된다.
**사고 이력**: 2026-08-25 ~ 10-02 위치를 `Fold.RAW` 관측치로 담았다. 값이 없어 74건 전부
0 이었고, 자비스의 "최근 값"에 "위치 0 · 0 · 0" 이 들어갔다. 2026-11-02 사건 표로 옮겼다
(`app/migrate.py`). 폰 단축어는 그대로 표본 모양으로 보내고, 서버가 갈라 담는다.

### 위치에는 어느 자동화가 보냈는지 라벨을 붙인다
```json
"meta": {"lat": ..., "lon": ..., "trigger": "wallet"}    ← 사건의 label 이 된다
```
**사고 이력**: 2026-08-26. 하루에 위치가 6개 찍혔는데 `떠날 때` 는 한 번만 발동한다.
지갑 자동화가 섞였다는 뜻인데 **어느 점이 카드 탭인지 구분할 수 없었다.**
좌표만으론 "집을 나선 지점"과 "교통카드를 찍은 지점"이 같아 보이고, 후자가 곧
'타는 곳'이라 그 구분이 이 섹터의 핵심 정보다.

### 하루에 여러 번이면 하나만 고른다
```
퇴근      Fold.LAST    나갔다 들어와도 마지막이 퇴근
출근 도착  Fold.FIRST   처음 도착이 출근
```
**이유**: 평균을 내면 3시와 7시 사이 어딘가라는, **실제로 일어나지 않은 시각**이 나온다.

## 금지사항

### ❌ 절대 기준으로 야근을 판정하지 않는다
```python
# ❌ 금지
if departure > 19.0: alert("야근")
```
**사고 이력**: 수면에서 이미 겪었다 (2026-08-21, "7시간 미만" 기준이면 88%의 날에 알림).
6시 퇴근이 평범한 사람과 9시 퇴근이 평범한 사람에게 같은 기준을 대면 한쪽은 매일
울리고 다른 쪽은 영영 안 울린다.

### ❌ 주말을 baseline 에 넣지 않는다
**이유**: 주 5일 패턴을 가진 사람의 "평소"는 평일로만 만들어야 한다.
주말 기록 하나가 평균을 몇 시간씩 끌어내린다.

### ❌ 끊김 기준을 수면과 같게 두지 않는다
```python
stale_after = timedelta(days=4)   # 수면·휴식기 심박은 42시간(밤 단위)
```
**이유**: 위치·퇴근은 평일에만 생기는 사건이고 주말·휴가·재택에 자연히 빈다.
수면 기준(36시간 → 2026-11 부터 42시간)을 쓰면 **매주 월요일마다** 수집이 멈췄다고 잔소리한다.

## 모듈 지도

| 파일 | 책임 |
|------|------|
| `metrics.py` | 퇴근/출근 시각 카드 (수집기 없음) |
| `events.py` | 위치 사건 카드. 2026-11 관측치에서 옮겼다 — 값이 없는 것을 숫자 칸에 담고 있었다 |
| `places.py` | 장소의 역할 후보(집·아침에 타는 곳·내리는 곳·저녁에 타는 곳). 평일, 한국 시각, 사흘 이상 |
| `triggers.py` | 사건 트리거 둘 — 평일 아침 평소보다 늦게 나섬, 평소와 다른 곳에서 첫 탑승. 관측치 트리거는 없다 |
| `inspect.py` | 쌓인 위치 사건을 훑어보는 도구. 패턴이 있는지부터 확인 (시간대는 한국 시각) |

# SPRINT 2026-11-02 — 2단계: 위치 사건, 장소, 루틴 이탈

## 목표

수집한 것을 "이 사람의 패턴"으로 바꾸는 2단계의 첫 스프린트. 위치에서 장소와 출근 루틴을, 수면에서
잠드는 리듬을 뽑고, 본인의 평소에서 벗어나면 말할 거리를 낸다. 숫자 계산은 코드가, 이름과 연결은
LLM 이 한다. 셋 모두 독립 리뷰를 거쳤다.

**2단계 끝 기준(출근 루틴과 탑승역이 DB 에 있고, 패턴 이탈로 첫 알림이 나감)은 앞 절반만 찼다.**
장소는 DB 에 있고, 역할(집·아침에 타는 곳·갈아타는 곳·회사 쪽 역)은 그 장소에서 계산된다. 첫 알림은
폰 위치가 다시 들어와야 나간다 — 10/02 이후 폰 데이터가 없다(BACKLOG "0단계 남은 것").

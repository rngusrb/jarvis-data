# SPRINT 2026-11-04 — 3단계 첫째: 주제 나무

## 목표

믿음(`beliefs`: kind 한 줄 + 회고마다 덮어쓰는 문장 + 글 근거 열둘)을 구조 재검토(2026-10)에서 정한 **주제 나무**로

리뷰에 넣었다.

  (주제·근거 연결·변경 기록·메모·회고 기록), 검사한 나무와의 차이를 한 트랜잭션에(`apply`, 읽은 뒤 바뀌었으면

  - 근거는 가장 구체적인 주제에 붙고, 셀 때는 접힌 가지까지 센다(`lineage`, 리뷰 재현에서 나왔다)

  - 변경 기록에 누가 바꿨나(`actor`) — 변경 빈도는 모델 것만 센다
